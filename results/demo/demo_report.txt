FLASK
  [vulnerable]
    SQL Injection      АТАКА ПРОЙШЛА      Отримано 3 чужих рядків (можливо, з хешами паролів)
    XSS (stored)       АТАКА ПРОЙШЛА      Payload повернувся без екранування — виконається у браузері
    IDOR               АТАКА ПРОЙШЛА      Отримано чужу нотатку: "Bob: секретний план проєкту"
  [secure]
    SQL Injection      ЗАБЛОКОВАНО        Пошук повернув 0 рядків — ін'єкція нейтралізована
    XSS (stored)       ЗАБЛОКОВАНО        Payload екранований (&lt;img ...&gt;) — JS не виконається
    IDOR               ЗАБЛОКОВАНО        Доступ заборонено (статус 403)
